# ETags

Official public tag system used by the ELIXR ecosystem for displaying custom user tags, groups, badges, and statuses across supported tools and overlays.

## What Is ETags?

ETags is a lightweight user-tagging system designed primarily for VRChat-related tools and overlays.  
It allows tools to display custom metadata beside users such as:

- Group tags
- Staff badges
- Special user roles
- Trusted/internal markers
- Custom colored tags
- Platform or status indicators

The goal of ETags is to provide a shared, expandable tagging standard that multiple tools can support and recognize.

---

## What Is It Used For?

ETags is commonly used for:

- In-game overlays
- Friend/player lists
- Moderation tools
- Community tools
- Social/status systems
- Shared ecosystem integrations

By making the tag list public, other tools can optionally support the same tags and provide a more unified experience across communities.

---

## Features

- Lightweight and easy to integrate
- Publicly accessible tag definitions
- Custom colors and styling support
- Group + user-specific tags
- Expandable structure
- Designed for real-time overlays and live user systems
- Shared ecosystem compatibility between tools

---

## How ELIXR Uses ETags

Within ELIXR, ETags are used to display enhanced information beside players inside overlays, player lists, notifications, and moderation systems.

Examples include:

- Official ELIXR users
- Staff members
- Developers
- Community roles
- Custom user tags
- Status indicators

ETags are purely visual and informational.

---

## Using ETags In Your Own Tool

You are welcome to integrate ETags into your own project or tool.

If you would like official permission, partnership consideration, or verified integration support, please contact me through the ELIXR Discord server.

Official integrations may receive:
- Early access to future tag updates
- Expanded compatibility support
- Verified/partnered status
- Additional ecosystem features in the future

---

## Notes

ETags is actively evolving alongside ELIXR.  
Structures, formats, and available tag types may expand over time.

---

## Getting a custom tag

ETags are generally free to most users, though it is up to my discression on if something is appropriate to be added.
If you would like access to customize your own tag or have animations, you will have to join the Official ELIXR Discord server and purchase the custom tag creation tool.
The tool gives you full access to change your tag however you want, whenever you want.
